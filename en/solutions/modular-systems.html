Module library

Proven modules — custom assembly

Every module is developed and validated in our own plants. The assembly is custom — the reliability of the components is proven.

🫗

Filling module — liquid

Volumetric and gravimetric versions, 1–24 filling heads. Interchangeable filling head geometries matched to material viscosity.

⚗️

Filling module — powder/granule

Screw, vibratory and bulk feeder variants. Accuracy ± 0.3%, automatic tare correction.

🏷

Labelling module

Self-adhesive and shrink-sleeve labels, for round and flat surfaces. Plug-and-play integration with conveyor module.

📦

Packaging module

Carton, bag, tray and box formats. Automatic size change via recipe call, <5 min changeover.

🔍

Inspection module

Weight check, machine vision, metal detection — unified data stream to the quality management system.

🖥

Control module

Unified HMI for all modules. OPC-UA output, recipe library, batch record — MES/ERP-ready.

🚿

CIP/SIP module

Automatic in-place cleaning — connectable to any affected module. GMP and FDA-compatible.

🚂

Conveyor module

Belt, roller and asynchronous motor-driven variants. Obstacle detection, speed synchronisation.

🔌

Integration module

Fitting to existing lines — between Nordexa and third-party equipment alike.
